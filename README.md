## `01` — Overview

This repository contains my personal portfolio website.

Built from scratch with a focus on **clean interfaces, subtle interactions, strong typography, and performance**.

No unnecessary frameworks.
No bloated dependencies.
Just a carefully crafted website that represents who I am and what I build.

---

## `02` — Experience

The portfolio is designed around a simple idea:

```text
           DESIGN
              ↓
        DEVELOPMENT
              ↓
          EXPERIENCE
              ↓
            IMPACT
```

Every section has a purpose — from the first interaction to the smallest hover animation.

### What you'll find

* **About** — A little bit about me
* **Skills** — Technologies & tools I work with
* **Projects** — Selected works and experiments
* **Experience** — My journey and experience
* **Contact** — Let's build something together

## `06` — Run Locally

Clone the repository:

```bash
git clone https://github.com/username/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Then simply open:

```text
index.html
```

Or run it using **Live Server** in VS Code.

No build process.
No package installation.
No configuration.

Just open and run.
