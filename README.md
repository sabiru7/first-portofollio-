## ◢ GETTING STARTED

### 01 — CLONE

```bash
git clone https://github.com/sabiru7/first-portofollio-.git
cd first-portofollio-
```

### 02 — INSTALL

```bash
npm install
```

### 03 — DEVELOPMENT

```bash
npm run dev
```

### 04 — BUILD

```bash
npm run build
```

### 05 — PREVIEW

```bash
npm run preview
```
