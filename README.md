## 🎨 Design System

### Primary Color

<div align="center">

| Color |    HEX    | Usage                     |
| :---: | :-------: | :------------------------ |
|   🔵  | `#0099FF` | Primary / CTA / Highlight |
|   🩵  | `#00D4FF` | Glow / Secondary Accent   |
|   ⬛   | `#050B14` | Main Background           |
|   🌑  | `#0A1424` | Card / Surface            |
|   ⚪   | `#F8FAFC` | Primary Text              |
|   ◽   | `#94A3B8` | Secondary Text            |

</div>

### Visual Direction

```css
:root {
  --primary: #0099FF;
  --accent: #00D4FF;

  --background: #050B14;
  --surface: #0A1424;
  --surface-hover: #0F1E33;

  --text: #F8FAFC;
  --text-muted: #94A3B8;

  --success: #22C55E;
  --warning: #F59E0B;
  --error: #EF4444;

  --glow:
    0 0 20px rgba(0, 153, 255, 0.35);
}
```
